# Privacy Policy for Gmail Agent

Last updated: November 18, 2026

## Purpose
Gmail Agent is a personal automation application
for managing emails, calendar events, and tasks.

## Data Access
The application accesses authorized Gmail messages,
attachments, and Google Calendar events.

## Data Usage
Data is processed to identify tasks, deadlines,
and scheduling information.

Relevant information may be transferred to Trello
and configured AI processing services solely
to provide these functions.

## Data Protection
Google user data must not be sold, used for
advertising, or used to train general-purpose
AI models.

## Data Deletion
Users can revoke access through their Google
Account settings and request deletion of
stored application data.

## Google API Compliance
The application is subject to the Google API
Services User Data Policy, including its
Limited Use requirements.
